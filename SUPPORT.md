# Support

## Self-hosting and development

- Read the [self-hosting guide](docs/self-hosting.md) and
  [operations](docs/booking-operations.md) first.
- Found a bug? [Open an issue](https://github.com/YCorpLabs/Scheduling/issues/new/choose) with the bug report
  template, including the commit you run and what you expected.
- Have an idea? Open an issue with the feature request template.
- Questions and feedback go to [Discussions](https://github.com/YCorpLabs/Scheduling/discussions).

## The hosted service

For help with meet.ycorplabs.com, email support@ycorplabs.com. Do not post
booking links, guest details or calendar data in public issues.

## Security

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
